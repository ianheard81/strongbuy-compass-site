- index.html
- assets/style.css

## Development/status wording
The page deliberately states that:
- StrongBuy Compass is in development
- current investment data may be demonstration data
- it is not a live recommendation service
- prototype screenshots should not be interpreted as financial advice

## Hosting
Because this is a static site, it can be deployed to:
- Railway
- Cloudflare Pages
- GitHub Pages
- Namecheap shared hosting
- Netlify / Vercel

Do not point the root domain away from its current DNS until the chosen host provides the exact DNS record(s).
